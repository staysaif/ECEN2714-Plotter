# ECEN 2714 Lab 6 — Passive RC Filters

Upload these four files into the `lab6/` folder of `staysaif/ECEN2714-Plotter` on the `main` branch. Leave the root Lab 5 files untouched.

The site plots RC LPF and RC HPF measurements using R=1 kΩ, C=10 nF, cutoff ≈15.92 kHz, with the exact 19 frequency rows (1, 2, 4, 6, 8, 10, 12, 16, 20, 25, 30, 40, 50, 60, 80, 100, 150, 200, and 400 kHz). Download the template at the live site. The example uses synthetic 10/12 GHz cutoff frequencies and is not lab data.
