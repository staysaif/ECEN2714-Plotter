How to use this tool

1. Download the templateUse the CSV with the 15 required lab frequencies. Enter only the columns you have measured.
2. Upload your CSVInclude input/output peak-to-peak voltages for gain, and/or phase in degrees. Complete every row of a response you want to plot.
3. Select and exportChoose magnitude, phase, or both; select one or more circuits. Each selected circuit gets its own graph(s), never overlaid.
Each circuit and response is independent. An entirely blank column is optional; a partially filled response is incomplete. Each table must retain its 15 listed frequency rows. Extra frequencies may be added to any table independently. Entirely blank measurement columns are optional; partially filled required measurements are reported as incomplete.

CSV template and measurements

Magnitude is calculated using 20 log₁₀(Vout,pp / Vin,pp). Enter phase as ∠Vout − ∠Vin, in degrees. The CSV contains two separate tables: RC LPF and RL HPF. Each has its own frequency column, so additional frequencies can be entered independently. Leave a circuit’s measurement columns blank until you measure it.

1. Download CSV Template

If your browser does not start the download, open the CSV template directly and save the file. The downloaded file has two tables, one for RC LPF and one for RL HPF.

Example notice: The synthetic example uses artificial 10 GHz (RC LPF) and 12 GHz (RL HPF) poles, with measurement points spanning three decades below and three decades above each pole. Real lab CSV files continue to use the lab frequencies and component values.

Cutoff frequency estimates

The tool estimates the passband level from the median of the first three points (LPF) or last three points (HPF), then interpolates the −3.0103 dB crossing versus log-frequency. Estimates require a complete magnitude response.
