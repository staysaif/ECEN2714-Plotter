QUICK GUIDE

Exporting data from LTspice

  1. Run the simulation and open its waveform viewer.
  2. Display the voltage or current traces you need.
  3. In the waveform viewer, select File → Export data as text (in some versions, Plot File → Export data as text).
  4. Select the traces and save the resulting .txt file, then import it above.

Do not export the binary .raw file. Text data is processed locally in your browser; rendering libraries are loaded from a CDN.
